# VRDTVSP QSF Worker (Attempt 06) - Call Structure

Generated by AST analysis of VRDTVSP_Run_QSF_with_v5_or_v6_attempt_06.py.
51 module-level functions. `main()` is the only root - every other
function is reachable from it, and there is no dead code.

Diagnostic leaf helpers (debug_print, status_print, warning_print,
error_print, _now_string) are called from almost everywhere. Showing them
as branches would bury the structure, so they appear in parentheses after
each function that calls them, and are not expanded.

## Notes

* `assert_main_sta_context` is the most widely shared non-diagnostic helper.
  That is why the CHG-15 bootstrap precondition guard was placed there: one
  guard covers every COM entry path in the tree.
* `bootstrap_com_runtime` is called from exactly one place, `main()`, and is
  its first statement. Nothing else in the tree can start the COM runtime.
* The tree contains no recursion.
